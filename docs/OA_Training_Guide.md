# ส่วนที่ 1 — พื้นฐานที่ทุกคนต้องรู้

## บทที่ 1 — One OA คืออะไร ใช้ทำอะไร

**ปัญหาเดิม:** การขออนุมัติด้วยกระดาษ/แชต/อีเมล — หาเอกสารไม่เจอ ไม่รู้ว่าใครดองอยู่ อนุมัติแล้วตามต่อไม่ได้

**One OA ช่วย:** ยื่นคำขอออนไลน์ → ระบบวิ่งหาผู้อนุมัติให้เอง **ตามตำแหน่งงานและวงเงิน** → ทุกคนเห็นสถานะเรียลไทม์ → อนุมัติแล้วส่งต่อบัญชี/ทรัพย์สินอัตโนมัติ

ใช้ยื่นเอกสารภายใน เช่น **ขอส่วนลด/ราคาพิเศษ, ค่าใช้จ่ายการตลาด, เบิกจ่าย, ใบลดหนี้ (CN), จัดซื้อ, เรียกคืนสินค้าเดโม, ค่าใช้จ่ายประจำวัน/สาขา, บันทึกข้อความทั่วไป**

**ภาพรวม 1 นาที:**
```
  คุณยื่นคำขอ ──► ระบบสร้างสายอนุมัติ ──► ผู้อนุมัติกด ✓ ทีละขั้น ──► อนุมัติครบ ──► ส่งบัญชี/ดำเนินการ
      │                                        │
      └── ติดตามสถานะได้ทุกขั้น ◄──────────────┘  (รู้ว่าตอนนี้รอใครอยู่)
```

## บทที่ 2 — เข้าสู่ระบบครั้งแรก

1. เปิดเว็บ One OA → หน้า **เข้าสู่ระบบ** (`/login`)
2. เลือกวิธีเข้า:
   - **เข้าสู่ระบบด้วยระบบกลาง (SSO)** — ปุ่มใหญ่ ใช้บัญชีพนักงานกลาง (แนะนำ ไม่ต้องจำรหัสแยก)
   - **อีเมล + รหัสผ่าน** — สำหรับบัญชีในระบบ
3. ครั้งแรกถ้าได้รหัสชั่วคราว ระบบจะ **บังคับเปลี่ยนรหัสผ่าน** (`/change-password`)
4. เข้าไป **ตั้งลายเซ็น + ภาษา** ที่เมนู **โปรไฟล์** (`/profile`) — ลายเซ็นจะไปปรากฏบนเอกสารที่พิมพ์

> 💡 ล็อกอินครั้งแรกผ่านระบบกลาง จะได้บทบาท **ผู้ใช้ทั่วไป (USER)** อัตโนมัติ ส่งคำขอได้ทันที แอดมินค่อยปรับบทบาท/ตำแหน่งงานให้ภายหลัง

## บทที่ 3 — ทัวร์หน้าจอ (เมนูทั้งหมด)

เมนูด้านซ้ายแบ่งเป็นกลุ่ม:

**🏠 ของฉัน**
- **แดชบอร์ด** (`/dashboard`) — ศูนย์รวมงานอนุมัติ ตัวเลข กราฟ การ์ด "ต้องจัดการตอนนี้"
- **ส่งคำขอ** (`/`) — หน้าแรก เลือกฟอร์มเพื่อยื่นคำขอ (จัดกลุ่ม + ค้นหา)
- **รอฉันอนุมัติ** — คำขอที่ค้างที่ขั้นของฉัน (มี **ป้ายตัวเลข** บอกจำนวน)
- **คำขอของฉัน** — คำขอที่ฉันเป็นคนยื่น

**📋 คำขอ**
- **ศูนย์การอนุมัติ** (`/requests`) — รวมทุกคำขอที่มีสิทธิ์เห็น มีแท็บ + ตัวกรอง + ส่งออก CSV
- **ตารางรวมเอกสาร** (`/requests/table`) — ตารางแน่น ไว้กวาดตา/ส่งออก
- **ภาพรวมรออนุมัติ** (`/requests/pending`) — เห็นทุกใบที่ค้างในสาย ว่า "ตอนนี้รอใคร" + ใครมีงานค้างมากสุด (คอขวด)

**⚙️ ดูแลระบบ** (เฉพาะแอดมิน) — ผู้ใช้/สิทธิ์, แม่แบบฟอร์ม, วิเคราะห์, เตือนงานค้าง, เชื่อมต่อ API, สำรองข้อมูล, SSO

**อื่น ๆ** — โปรไฟล์/ลายเซ็น/อนุมัติแทน (`/profile`), คู่มือ + ผู้ช่วย AI (`/help`)

## บทที่ 4 — ศัพท์ที่ต้องเข้าใจก่อน (สำคัญมาก)

ระบบนี้มี **2 สิ่งที่คนสับสนบ่อย** ต้องแยกให้ออก:

### 🅐 บทบาท (Role) — คุมว่า "เห็นอะไร / จัดการอะไรได้"
| บทบาท | เห็นอะไร |
|---|---|
| **ADMIN** ผู้ดูแลระบบ | เห็นและจัดการได้ทุกอย่าง |
| **MANAGER** หัวหน้าทีม | เห็นเอกสารทุกฉบับ **ของคนในแผนกตัวเอง** |
| **USER** ผู้ใช้ทั่วไป | เห็นเฉพาะ **ของตัวเอง + ที่ตนอยู่ในสายอนุมัติ + ที่ถูกสำเนาถึง** |

ธงพิเศษ **ตรวจสอบได้ (can_audit)** = เห็นทุกใบเพื่อสอบทาน แต่ **อนุมัติ/แก้ไม่ได้** (ผู้ตรวจสอบ)

### 🅑 ตำแหน่งงาน (JobRole) — คุมว่า "อยู่ในสายอนุมัติตรงไหน"
`ผู้แทนขาย (SALES)` · `ผู้จัดการฝ่ายขาย (SALES_MANAGER)` · `ฝ่ายจัดซื้อ (PURCHASING)` · `ฝ่ายการตลาด (MARKETING)` · `ฝ่ายบัญชี-การเงิน (FINANCE)` · `ผู้จัดการฝ่ายบัญชี (FINANCE_MANAGER)` · `กรรมการผู้จัดการ (MD)` · `ไม่ระบุ (NONE)`

> 📌 **จำให้ขึ้นใจ:** สายอนุมัติใช้ **ตำแหน่งงาน (JobRole)** ไม่ใช่บทบาท (Role) · เช่น เอกสารวิ่งไปหา "ผู้จัดการฝ่ายบัญชี" = คนที่ตั้ง JobRole = FINANCE_MANAGER ไม่เกี่ยวกับว่าเขาเป็น ADMIN/USER

### สถานะเอกสาร (จำ 7 สถานะนี้)
| สถานะ | ความหมาย |
|---|---|
| **ฉบับร่าง (DRAFT)** | ยังไม่ส่ง กรอกค้างไว้ |
| **รออนุมัติ (PENDING)** | ส่งแล้ว กำลังวิ่งในสายอนุมัติ |
| **อนุมัติเบื้องต้นแล้ว (PRELIM_APPROVED)** | ผ่านขั้นหลักการแล้ว รอยื่นวงเงินจริง |
| **อนุมัติแล้ว (APPROVED)** | ผ่านครบทุกขั้น ✅ |
| **ไม่อนุมัติ (REJECTED)** | ถูกปฏิเสธ (ปิดเอกสาร) |
| **ถูกส่งกลับให้แก้ (RETURNED)** | ผู้อนุมัติให้แก้แล้วส่งใหม่ (ยังไม่ปิด) |
| **ยกเลิก (CANCELLED)** | ยกเลิกเอกสาร |

### ขั้นอนุมัติ 2 ระดับ (Stage)
- **อนุมัติเบื้องต้น (PRELIM)** = ขออนุมัติ "หลักการ" ก่อนรู้ยอดจริง (เฉพาะบางฟอร์ม)
- **อนุมัติจริง (FINAL)** = ยื่นวงเงินจริง → **วงเงินนี้แหละที่กำหนดว่าต้องผ่านใครบ้าง**

## บทที่ 5 — วงจรเอกสารตั้งแต่ต้นจนจบ

```
  (สร้าง) ──► ฉบับร่าง
                 │ กด "ส่งคำขอ"
                 ▼
             รออนุมัติ ◄───────────────┐
             │   │   │                 │ แก้แล้วส่งใหม่
   อนุมัติครบ│   │   │ ส่งกลับให้แก้     │
             │   │   └──► ถูกส่งกลับ ────┘
             │   │ ไม่อนุมัติ
             │   └──► ไม่อนุมัติ (ปิด)
             ▼
   ┌─ ถ้าเป็นขั้นเบื้องต้น ─► อนุมัติเบื้องต้นแล้ว ─(ยื่นวงเงินจริง)─► กลับไป "รออนุมัติ" (ขั้นจริง)
   │
   └─ ถ้าเป็นขั้นจริง ─────► อนุมัติแล้ว ✅ ─► ส่งบัญชี/เคลียร์ OA ─► เสร็จสิ้น
```

- **ดึงกลับมาแก้** ได้เฉพาะตอน "รออนุมัติ" และ **ยังไม่มีใครในขั้นปัจจุบันกดตัดสิน**
- **ยกเลิก** ได้ก่อนอนุมัติ · อนุมัติแล้วยกเลิกเองไม่ได้ → ต้องให้แอดมินทำ "ยกเลิกเอกสารที่อนุมัติแล้ว" พร้อมเหตุผล

# ส่วนที่ 2 — สำหรับผู้จัดทำ (ยื่นคำขอ)

## บทที่ 6 — ส่งคำขอทีละขั้น 🎯

**ขั้นตอน:**
1. เมนู **ส่งคำขอ** (หน้าแรก) → เลือกการ์ดฟอร์มที่ต้องการ (เช่น "เบิกจ่าย")
2. ระบบเปิดฟอร์ม → **กรอกข้อมูล** (ระบบ **บันทึกร่างอัตโนมัติ** ให้ตลอด ไม่ต้องกลัวข้อมูลหาย)
3. ฟอร์มที่มี **ตารางรายการ** → กดเพิ่มแถวได้หลายรายการ ช่อง "ยอดรวม/มูลค่า" จะบวกให้เอง (เบิกจ่าย = รวมจำนวนเงินทุกแถว · จัดซื้อ = รวม จำนวน × ราคา/หน่วย ทุกแถว) — **แก้เองไม่ได้ และเซิร์ฟเวอร์คิดซ้ำตอนส่ง** กันกรอกยอดต่ำกว่าจริงเพื่อข้ามขั้นอนุมัติ
4. **แนบไฟล์** ได้ทั้งระดับเอกสาร และในแต่ละแถวของตาราง (ไฟล์ละไม่เกิน **10 MB**)
5. ด้านข้างจะมี **พรีวิวสายอนุมัติสด ๆ** — เห็นเลยว่าเอกสารจะวิ่งไปหาใครบ้าง
6. กด **ส่งคำขอ** → เข้าสายอนุมัติ (สถานะเป็น "รออนุมัติ")

> **ตัวอย่างจริง — เบิกจ่าย (REIMBURSE):**
> - หัวเรื่อง: "เบิกค่าเดินทางพบลูกค้า ต.ค."
> - ตารางค่าใช้จ่าย: แถว 1 "ค่าแท็กซี่" 450 บาท, แถว 2 "ค่าที่พัก" 1,200 บาท → ช่อง "ยอดเบิกรวม" ขึ้น **1,650** ให้เอง (คือ "วงเงิน" ที่ใช้ตัดสินสายอนุมัติ — ไม่ต้องกรอกเอง)
> - แนบรูปใบเสร็จ → กดส่ง

✅ **เช็กลิสต์ก่อนกดส่ง:** หัวเรื่องชัด · วงเงินถูก · แนบใบเสร็จ/หลักฐานครบ · ดูพรีวิวสายอนุมัติว่าถูกคน

## บทที่ 7 — กรณีพิเศษตอนกรอก (ลงลึก)

- **วงเงินกำหนดสายอนุมัติ:** ช่อง "วงเงิน (AMOUNT)" ยิ่งมาก ยิ่งต้องผ่านคนมากขึ้น (ดูเกณฑ์บทที่ 15) · ฟอร์มที่กรอกยอดเอง → กรอกให้ตรงจริง · **ฟอร์มที่มีตารางรายการ (เบิกจ่าย/จัดซื้อ)** วงเงินมาจากยอดรวมของตารางอัตโนมัติ แก้เองไม่ได้
- **อนุมัติเบื้องต้น → ยื่นจริง:** บางฟอร์ม (เช่น ส่วนลด/การตลาด/จัดซื้อ) มีขั้น "เบื้องต้น" ให้ขออนุมัติหลักการก่อน พอผ่านเป็น "อนุมัติเบื้องต้นแล้ว" → กด **"ยื่นอนุมัติจริง"** แล้วใส่ **วงเงินจริง** (ระบบจะคำนวณสายอนุมัติใหม่ตามยอดจริง)
- **ยื่นล่วงหน้า (Lead time):** บางฟอร์มกำหนดให้ยื่นก่อนวันใช้งานกี่วัน · ถ้ายื่นกระชั้น ระบบอาจ **เตือน** (ต้องใส่เหตุผลเร่งด่วน) หรือ **บล็อก** ไม่ให้ส่ง
- **อ้างอิงเอกสารเดิม / ทยอยเบิกเป็นงวด:** ฟอร์มที่มีช่อง "อ้างอิงคำขอที่อนุมัติแล้ว" ใช้เบิกย่อยจากวงเงินที่อนุมัติไว้ · ระบบจะเตือนถ้าเบิกเกินวงเงินต้นเรื่อง
- **บันทึกร่าง:** กด "บันทึกร่าง" เก็บไว้ก่อน หรือปล่อยให้ autosave แล้วมาส่งทีหลังที่ "คำขอของฉัน"

## บทที่ 8 — ติดตามคำขอ

เปิดเอกสารที่เมนู **คำขอของฉัน** → ในหน้ารายละเอียดมี 3 แท็บ:
- **รายละเอียด** — ข้อมูลที่กรอก + ไฟล์แนบ
- **สายอนุมัติ (Flow)** — เห็นทุกขั้น ใครอนุมัติแล้ว/ยังรอใคร (ไทม์ไลน์)
- **ความคิดเห็น** — คุยกับผู้อนุมัติ แนบไฟล์เพิ่มได้

ด้านขวามี **ประวัติการทำรายการ (Audit)** ไล่สีตามเหตุการณ์ (เขียว=อนุมัติ, แดง=ไม่อนุมัติ/ยกเลิก, ส้ม=ส่งกลับ)

> 💡 อยากรู้ว่า "ตอนนี้ค้างที่ใคร" → ดูแท็บสายอนุมัติ หรือหน้า **ภาพรวมรออนุมัติ** (เวลารอไล่สี: ≥3 วันส้ม, ≥7 วันแดง)

**การแจ้งเตือน:** ระบบส่งแจ้งเตือนผ่าน **Lark (การ์ด/แชต) และอีเมล** อัตโนมัติ — เมื่อถึงคิวคุณ, เมื่อผลออก, เมื่อถูกสำเนาถึง (CC) · หน้าแรกมีการ์ด "สำเนาถึงฉันที่ยังไม่ได้อ่าน"

## บทที่ 9 — เมื่อถูกส่งกลับ / ไม่อนุมัติ / จะดึงกลับ / ยกเลิก

| สถานการณ์ | ทำยังไง |
|---|---|
| **ถูกส่งกลับให้แก้ (RETURNED)** | เปิดเอกสาร → ดูเหตุผล → แก้ → กด **"ส่งอีกครั้ง"** (วิ่งสายอนุมัติใหม่) |
| **ไม่อนุมัติ (REJECTED)** | เอกสารปิดแล้ว ยื่นใหม่เป็นฉบับใหม่ |
| **อยากแก้เอง (ดึงกลับ)** | กด "ดึงกลับ" ได้เฉพาะตอน "รออนุมัติ" และยังไม่มีใครในขั้นนั้นกดตัดสิน → กลับเป็นฉบับร่าง (หรือย้อนไปขั้นเบื้องต้น) |
| **ยกเลิก** | กดยกเลิกได้ก่อนอนุมัติ · อนุมัติแล้วให้แจ้งแอดมิน |

## บทที่ 10 — การเคลียร์ค่าใช้จ่ายใน OA

**หลักการ:** One OA = "อนุมัติก่อน แล้วค่อยไปตั้งเบิกจริงในระบบ OA/ERP โดยอ้างเลขอนุมัตินี้" · การเคลียร์คือการยืนยันว่าตั้งเบิกจริงแล้ว

- บางฟอร์มกำหนด **ต้องเคลียร์ภายใน N วันหลังอนุมัติ**
- พออนุมัติแล้ว → ไปตั้งเบิกในระบบ OA จริง → กลับมา **บันทึก "เลขที่เอกสารใน OA"** ในเอกสารนี้เพื่อปิดการเคลียร์
- ระบบ **เตือนล่วงหน้า ≤3 วัน** และเมื่อเลยกำหนด
- ดูสถานะที่แท็บ **"รอเคลียร์ OA"** และการ์ดหน้าแรก

# ส่วนที่ 3 — สำหรับผู้อนุมัติ

## บทที่ 11 — อนุมัติทีละขั้น 🎯

1. ไปเมนู **รอฉันอนุมัติ** (ป้ายตัวเลขบอกจำนวนงานค้าง) — หรือดูจากการ์ดแจ้งเตือน Lark
2. เปิดเอกสาร → ถ้าถึงคิวคุณ จะมี **แผงตัดสิน (ขอบสีเหลือง)** ขึ้นมา
3. อ่านรายละเอียด + ไฟล์แนบ + สายอนุมัติ แล้วเลือก:

| ปุ่ม | ใช้เมื่อ | ต้องใส่เหตุผล? |
|---|---|---|
| **✓ อนุมัติ** | เห็นชอบ | ไม่บังคับ (ใส่ความคิดเห็นได้) |
| **✕ ไม่อนุมัติ** | ปฏิเสธ (ปิดเอกสาร) | **ต้องใส่เหตุผล** |
| **↩ ส่งกลับให้แก้** | ให้ผู้ยื่นแก้แล้วส่งใหม่ (ไม่ปิดเอกสาร) | **ต้องใส่เหตุผล** |

> ⚠️ "ไม่อนุมัติ" = ปิดจบ · "ส่งกลับให้แก้" = ให้โอกาสแก้ — เลือกให้ถูกเจตนา

## บทที่ 12 — เครื่องมือผู้อนุมัติ (ลงลึก)

- **→ ถ่ายโอน** — ส่งงานในคิวให้คนอื่นพิจารณาแทน (เลือกคน + ใส่โน้ต)
- **+ เพิ่มผู้อนุมัติ** — แทรกผู้อนุมัติ **ก่อน/หลัง** ขั้นของคุณ (เลือกจากตำแหน่งงาน / ผู้ใช้ / ไดเรกทอรีด้วยอีเมล)
- **แนบไฟล์/รูป** — แนบหลักฐานพร้อมการตัดสินในครั้งเดียว
- **ความคิดเห็น** — คุยในเอกสาร แนบไฟล์ได้

> 💡 อนุมัติ **ผ่านการ์ด Lark / อีเมล** ได้เลย — ปุ่มอนุมัติ/ไม่อนุมัติในการ์ดทำงานเหมือนในเว็บทุกประการ และการ์ดจะอัปเดตเมื่อมีคนตัดสินแล้ว

## บทที่ 13 — อนุมัติแทน (Delegation)

- ตั้งได้เองที่ **โปรไฟล์** หรือแอดมินตั้งให้ — ระบุ **ช่วงวันที่ + เหตุผล**
- ช่วงที่มอบหมาย คนรับแทนจะ **กดอนุมัติแทนเจ้าของคิวได้** ระบบบันทึกว่า "(อนุมัติแทน …)"
- เจ้าของคิวที่ลา ระบบส่งแจ้งเตือนไปหาผู้รับแทนให้เอง
- ⚠️ **ข้อห้าม:** ใช้สิทธิ์รับแทนอนุมัติ **เอกสารของตัวเอง** ไม่ได้ · มอบแทนได้ชั้นเดียว (ไม่ต่อทอด)

# ส่วนที่ 4 — เข้าใจเบื้องหลัง (สำหรับคนอยากรู้ลึก)

## บทที่ 15 — สายอนุมัติทำงานอย่างไร ★

สายอนุมัติของแต่ละฟอร์มคือ **ลำดับขั้น (step)** แต่ละขั้นตั้งค่าได้:

- **ที่มาของผู้อนุมัติ:** ตามตำแหน่งงาน (เช่น "ผู้จัดการฝ่ายบัญชี") หรือระบุตัวบุคคล
- **ขอบเขต:** ในแผนกของผู้ขอ (DEPT) หรือใครก็ได้ที่ถือตำแหน่งนั้น (ANY)
- **โหมดขั้น:**
  - **คนเดียว (SEQUENTIAL)** — คนนั้นคนเดียว
  - **ใครก็ได้ 1 คน (ANY)** — มีหลายคน ใครกดก่อนผ่านเลย คนอื่นข้าม
  - **ต้องครบทุกคน (ALL)** — ทุกคนต้องอนุมัติจึงไปต่อ
- **ชนิดขั้น:** ต้องอนุมัติ (APPROVE) หรือ **สำเนาถึง (CC)** = แค่แจ้งให้ทราบ ไม่บล็อก
- **เงื่อนไขวงเงิน:** เช่น "ตั้งแต่ 100,000 ขึ้นไป" จึงเพิ่มขั้นผู้จัดการฝ่ายบัญชี

**กฎอัตโนมัติ 3 ข้อ:**
1. คนที่อนุมัติไปแล้วในขั้นก่อน **ไม่ต้องอนุมัติซ้ำ** ในขั้นถัดไป
2. ขั้นที่ **ไม่เหลือผู้อนุมัติที่เข้าเกณฑ์** จะถูก **ข้าม**
3. ถ้าตำแหน่งที่ตั้งไว้ **ไม่มีใครถืออยู่** ระบบเตือน "ยังไม่มีผู้ใช้งานที่ถือตำแหน่ง: …"

> **ตัวอย่างไล่ทีละขั้น — ฟอร์มส่วนลด (DISCOUNT):**
> - **เบื้องต้น:** หัวหน้าฝ่ายขาย (ในแผนกผู้ขอ)
> - **จริง (ขึ้นกับวงเงิน):**
>   1. หัวหน้าฝ่ายขาย — เสมอ
>   2. ผู้จัดการฝ่ายบัญชี — **ถ้าวงเงิน ≥ 100,000**
>   3. กรรมการผู้จัดการ (MD) — **ถ้าวงเงิน ≥ 500,000**
>   4. แจ้งฝ่ายบัญชี (สำเนาถึง)
> → ขอส่วนลด 80,000 ผ่านแค่หัวหน้าฝ่ายขาย · ขอ 600,000 ต้องผ่านครบถึง MD

**เกณฑ์วงเงินมาตรฐาน (ค่าเริ่มต้น):**
| ฟอร์ม | +ผู้จัดการฝ่ายบัญชี | +กรรมการผู้จัดการ (MD) |
|---|---|---|
| ส่วนลด (DISCOUNT) | ≥ 100,000 | ≥ 500,000 |
| จัดซื้อ (PURCHASE) | ≥ 50,000 | ≥ 300,000 |
| เบิกจ่าย (REIMBURSE) | ≥ 20,000 | ≥ 100,000 |
| การตลาด (MARKETING) | — | ≥ 100,000 |
| ใบลดหนี้ (CREDIT_NOTE) | — | ≥ 50,000 |
| ค่าใช้จ่ายประจำวัน/สาขา | ผ่านทุกใบ (หัวหน้า → ผจก.บัญชี → MD) | |

> 📌 ผู้จัดทำ **เห็นสายอนุมัติจริงล่วงหน้า** ในหน้ากรอกฟอร์ม (พรีวิวใช้ตรรกะเดียวกับของจริงเป๊ะ)

# ส่วนที่ 6 — อ้างอิงเร็ว

## ❓ คำถามที่พบบ่อย (FAQ)

**Q: ส่งคำขอแล้วไม่รู้ว่าอยู่ที่ใคร?**
→ เปิดเอกสาร แท็บ "สายอนุมัติ" หรือดูหน้า "ภาพรวมรออนุมัติ"

**Q: ทำไมเอกสารของฉันผ่านคนน้อยกว่าเพื่อน?**
→ เพราะ **วงเงินต่างกัน** (ยอดสูงต้องผ่านผู้บริหารเพิ่ม — ดูบทที่ 15)

**Q: กรอกผิดหลังส่งไปแล้ว ทำยังไง?**
→ ถ้ายังไม่มีใครตัดสิน กด "ดึงกลับ" มาแก้ · ถ้ามีคนตัดสินแล้ว ขอให้ผู้อนุมัติ "ส่งกลับให้แก้"

**Q: ลาพักร้อน งานอนุมัติจะค้างไหม?**
→ ตั้ง "อนุมัติแทน" ที่โปรไฟล์ก่อนลา (บทที่ 13)

**Q: อนุมัติผ่านมือถือได้ไหม?**
→ ได้ กดปุ่มในการ์ด Lark ได้เลย

**Q: ระบบมองไม่เห็นเอกสารของเพื่อน?**
→ ปกติ — USER เห็นเฉพาะของตัวเอง + ที่อยู่ในสาย/CC (ดูบทที่ 4)
