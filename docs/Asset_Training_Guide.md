# ส่วนที่ 1 — พื้นฐานที่ทุกคนต้องรู้

## บทที่ 1 — ONE Asset คืออะไร ใช้ทำอะไร

**ปัญหาเดิม:** ทะเบียนทรัพย์สินอยู่ใน Excel หลายไฟล์ — ไม่รู้ของอยู่ไหน ใครถือ คิดค่าเสื่อมมือ ตรวจนับยาก ตัวเลขไม่ตรงบัญชี

**ONE Asset ช่วย:** รวมทรัพย์สินทุกชิ้นไว้ที่เดียว — รับของเข้าจาก OA/บัญชี/PEAK อัตโนมัติ → ลงทะเบียน → **คิดค่าเสื่อมให้เอง** → ติดฉลาก QR → ตรวจนับ → ส่งตัวเลขเข้าบัญชี

**วงจรชีวิตทรัพย์สิน (ภาพรวม 1 นาที):**
```
  แหล่งที่มา ──► นำเข้า/ตรวจสอบ ──► ลงทะเบียน (ร่าง) ──► เปิดใช้งาน (ACTIVE)
  (OA/บัญชี/PEAK/ไฟล์)                                        │
                                                             ▼
                              คิดค่าเสื่อมรายเดือน ──► ตรวจนับประจำปี ──► จำหน่าย/เก็บถาวร
```

## บทที่ 2 — เข้าสู่ระบบ

1. เปิดเว็บ ONE Asset → หน้า **เข้าสู่ระบบ**
2. กด **"เข้าสู่ระบบด้วยระบบกลาง (SSO)"** — ใช้บัญชีพนักงานกลาง (ระบบเดียวกับ OA/ONEBOOK)
3. สลับภาษาได้ (ไทย / EN / 中文) ที่แถบบน
4. มุมขวาบนมี **โปรไฟล์** (รูป + ชื่อ + บทบาท)

> 📌 **สิทธิ์ของคุณถูกกำหนดโดยระบบ ONE Asset เอง** (ไม่ใช่ SSO) — แอดมินตั้งบทบาทให้ที่หน้า "ผู้ใช้และสิทธิ์"

## บทที่ 4 — ศัพท์ที่ต้องเข้าใจก่อน

### 🅐 บทบาท (Role) — มี 4 แบบ
| บทบาท | ทำอะไรได้ |
|---|---|
| **เจ้าหน้าที่บัญชีทรัพย์สิน (ACCOUNTANT)** | งานประจำวัน: สร้าง/แก้ร่าง, นำเข้า, คิดค่าเสื่อม, อัปโหลดเอกสาร, ส่งออกรายงาน |
| **หัวหน้าบัญชี (MANAGER)** | สิทธิ์ ACCOUNTANT + **อนุมัติทรัพย์สิน + ปิดงวดค่าเสื่อม + แก้หมวดหมู่/ผังบัญชี** |
| **ผู้ดูแลระบบ (ADMIN)** | จัดการผู้ใช้/สิทธิ์/ข้อมูลหลัก/การเชื่อมต่อ + แก้หมวดหมู่ (ไม่ยุ่งงานบัญชีโดยตรง) |
| **ผู้ตรวจสอบ/ผู้ดู (AUDITOR)** | ดูทุกอย่าง + ส่งออกรายงาน แต่ **แก้ไขไม่ได้** |

> ⚠️ **สังเกต:** ADMIN **ไม่มีสิทธิ์ "สร้างทรัพย์สิน" ตามค่าเริ่มต้น** (เป็นของ ACCOUNTANT/MANAGER) — ถ้าแอดมินต้องนำเข้าทรัพย์สินเองด้วย ให้ไปติ๊กสิทธิ์ที่เมทริกซ์ (บทที่ 9)

### 🅑 สถานะทรัพย์สิน (10 สถานะ)
| สถานะ | ความหมาย |
|---|---|
| **รอตรวจสอบ (CANDIDATE)** | ยังเป็นรายการในคิว ยังไม่เป็นทรัพย์สิน |
| **ฉบับร่าง (DRAFT)** | สร้างแล้วแต่ยังกรอกไม่ครบ |
| **รออนุมัติ (PENDING_REVIEW)** | รอหัวหน้าอนุมัติ |
| **ใช้งาน (ACTIVE)** | อนุมัติแล้ว กำลังคิดค่าเสื่อม ✅ |
| **ไม่ใช้งาน (INACTIVE)** | หยุดใช้ชั่วคราว |
| **ส่งซ่อม (UNDER_REPAIR)** | อยู่ระหว่างซ่อม |
| **พักใช้ชั่วคราว (TEMPORARILY_UNUSED)** | พักการใช้ |
| **รอจำหน่าย (DISPOSAL_PENDING)** | เตรียมจำหน่าย |
| **จำหน่ายแล้ว (DISPOSED)** | ขาย/ทิ้ง/สูญหายแล้ว |
| **เก็บถาวร (ARCHIVED)** | เก็บประวัติ |

### 🅒 คำที่เจอบ่อย
- **รหัสทรัพย์สิน** = `SHD-<หมวด>-ปี-ลำดับ` เช่น `SHD-OFE-26-00001` (ออกอัตโนมัติ)
- **หมวดหมู่ 2 ระดับ** = หมวดหลัก (เช่น อุปกรณ์สำนักงาน) → หมวดย่อย (เช่น คอมพิวเตอร์)
- **ค่าเสื่อมราคา** = การทยอยตัดมูลค่าทรัพย์สินตามอายุการใช้งาน (ระบบคิดให้)
- **มูลค่าสุทธิ (NBV)** = ราคาทุน − ค่าเสื่อมสะสม

## บทที่ 5 — วงจรชีวิตทรัพย์สินเต็มรูปแบบ

```
  รอตรวจสอบ ──(สร้างจากคิว)──► ฉบับร่าง ──► รออนุมัติ ──(หัวหน้าอนุมัติ)──► ใช้งาน
  (CANDIDATE)                  (DRAFT)    (PENDING_REVIEW)                (ACTIVE)
                                                                           │
                    ┌──────────────────────────────────────────────────────┤
                    ▼                        ▼                     ▼        ▼
              คิดค่าเสื่อมทุกเดือน      ส่งซ่อม/พักใช้          ย้าย/โอน    จำหน่าย/เก็บถาวร
                                                                      (DISPOSED/ARCHIVED)
```

> 💡 ของที่ **นำเข้าจากไฟล์ (ของเดิม)** จะเป็นสถานะ **ใช้งาน (ACTIVE) ทันที** พร้อมยอดยกมา · ของที่ **รับจาก OA/บัญชี/PEAK** จะเริ่มที่ **ฉบับร่าง** ให้ตรวจ/อนุมัติก่อน

# ส่วนที่ 2 — ตั้งค่าระบบครั้งแรก (แอดมิน/หัวหน้า)

> ⏱️ ทำครั้งเดียวตอนเริ่มระบบ ตามลำดับนี้

## บทที่ 6 — ตั้งค่าข้อมูลหลัก (`/settings`)
8 แท็บ:
1. **บริษัท / สาขา / แผนก / ศูนย์ต้นทุน** — โครงสร้างองค์กร
2. **เลขที่เอกสาร** — เลขรันอัตโนมัติ (พรีวิวได้)
3. **เชื่อมต่อ OA** — endpoint, วิธียืนยันตัวตน, โหมด sync, ปุ่มทดสอบการเชื่อมต่อ
4. **ผู้ใช้งาน / สิทธิ์การใช้งาน** — เมทริกซ์ RBAC (ดูบทที่ 9)

## บทที่ 7 — ผังสถานที่ (`/locations`)
วางผัง **บริษัท → สาขา → อาคาร → ชั้น → ห้อง** → ใช้ระบุที่ตั้งทรัพย์สินและใช้ตอนตรวจนับ

## บทที่ 8 — หมวดหมู่ + ผังบัญชี + นโยบายค่าเสื่อม (`/categories`) ★
นี่คือ **รากฐานการคิดค่าเสื่อมและลงบัญชี** — ตั้งให้ครบก่อนนำเข้าทรัพย์สิน

แต่ละหมวดย่อยมี:
- **ชื่อ** (TH/EN/ZH) + **หน่วย**
- **ผังบัญชี 3 ตัว:** บัญชีสินทรัพย์ / บัญชีค่าเสื่อม / บัญชีค่าเสื่อมสะสม
- **อายุการใช้งาน (ปี)** + **มูลค่าซาก** + **วิธีคิดค่าเสื่อม** (เส้นตรง SL / ยอดลดลง DB / ตามการใช้งาน UOP)

**นโยบายค่าเสื่อม (1 ชุดต่อหมวดหลัก):** วิธี, อายุ, มูลค่าซาก, **กฎเริ่มคิด** (วันพร้อมใช้ / วันได้มา), **การเฉลี่ย** (เต็มเดือน / ตามวันจริง / เดือนถัดไป)

> 💡 ตั้งหมวดได้ 2 ทาง: กรอกมือในหน้านี้ หรือ **นำเข้าจากเทมเพลต PEAK** (บทที่ 12) — หมวดที่ไม่มีระบบจะสร้างให้อัตโนมัติ

## บทที่ 9 — ผู้ใช้และสิทธิ์ (`/admin/users`)
- **เพิ่มผู้ใช้:** ค้นหาพนักงานจากไดเรกทอรีกลาง (พิมพ์ชื่อ) → เลือก → กำหนดบทบาท
- **แท็บ "สิทธิ์ตามบทบาท":** เมทริกซ์ **ติ๊กได้** — เลือกบทบาท แล้วติ๊กว่าทำสิทธิ์ไหนได้บ้าง (14 สิทธิ์ 3 กลุ่ม) มีผลกับทุกคนในบทบาทนั้นทันที
- สิทธิ์ล็อก: "จัดการผู้ใช้" เปิดเฉพาะ ADMIN · "ลบบันทึกตรวจสอบ" ปิดตายทุกคน

# ส่วนที่ 3 — นำทรัพย์สินเข้าระบบ

## บทที่ 10 — ทางเข้าทั้งหมด (ภาพรวม + หลักเกณฑ์)

| ทาง | ที่มา | หลักเกณฑ์ | สถานะเริ่มต้น |
|---|---|---|---|
| **ดึง API** | OA (คำขอซื้ออนุมัติแล้ว) / ONEBOOK (บิลลงบัญชีแล้ว รหัส 12xx) / PEAK (ค่าใช้จ่ายผังบัญชี 12xx) | เข้าคิวตรวจ → อนุมัติ | **ร่าง → รออนุมัติ** |
| **นำเข้าไฟล์** | Excel (ฟอร์แมตระบบ) / วางจาก PEAK / เทมเพลต PEAK (กลุ่ม+สินทรัพย์) | ของเดิมที่ใช้งานอยู่ | **ใช้งาน (ACTIVE)** |
| **เพิ่มมือ** | รายชิ้นเฉพาะกิจ | กรอกฟอร์มเอง | ตามที่เลือก |

**เกณฑ์ร่วม:**
- 📌 **ขึ้นทะเบียนเป็นทรัพย์สินเมื่อมูลค่า ≥ 3,000 บาท** (ตั้งค่าได้) — ต่ำกว่าถือเป็นค่าใช้จ่าย
- **กันซ้ำ:** ไฟล์กัน **รหัสซ้ำ** · API กัน **เลขเอกสารต้นทางซ้ำ** (resync ไม่เพิ่มของเดิม) · หน้าคิวมี **ธงเตือนซ้ำ** ด้วยเลขใบกำกับ/PO (ข้ามแหล่งได้)
- **สิทธิ์:** นำเข้าสินทรัพย์ = "สร้างทรัพย์สิน" (ACCOUNTANT/MANAGER) · นำเข้ากลุ่ม/หมวด = "แก้หมวดหมู่" (MANAGER/ADMIN)

> 💡 สรุป: **ของใหม่ซื้อผ่านระบบ** → มาทาง OA/บัญชี/PEAK · **ของเดิมยกเข้า** → นำเข้าไฟล์/เทมเพลต · **รายชิ้น** → เพิ่มมือ

## บทที่ 11 — รับของจาก OA/บัญชี/PEAK (คิวรีวิว) 🎯
ที่เมนู **นำเข้าจาก OA** (`/oa-import`):
1. กดปุ่มดึง: **ดึงข้อมูลจาก OA** / **นำเข้าจากบัญชี (ONEBOOK)** / **นำเข้าจาก PEAK** → รายการเข้าคิว (สถานะ "รอตรวจสอบ")
2. เปิดแต่ละรายการ → **ตรวจ/แก้ข้อมูล** → **เลือกหมวดย่อย** (แยกเป็นหลายชิ้นได้ถ้า 1 บิลมีหลายตัว)
3. กด **"สร้างทรัพย์สิน"** → ได้ทรัพย์สินสถานะ **ฉบับร่าง** → หัวหน้าอนุมัติเป็น **ใช้งาน**
> คิวมีสถานะ: ใหม่ → กำลังตรวจ → พร้อมสร้าง → สร้างแล้ว (หรือ ปฏิเสธ/ซ้ำ/ผิดพลาด)

## บทที่ 12 — นำเข้าไฟล์ Excel / รูปแบบ PEAK 🎯
ที่ **ทะเบียนทรัพย์สิน** → ปุ่ม **"นำเข้า Excel"** หรือ **"นำเข้ารูปแบบ PEAK"**

**แบบที่ 1 — Excel ฟอร์แมตระบบ:** ดาวน์โหลดเทมเพลต → กรอก → อัปโหลด → ตรวจ error (ต้องมีรหัส, หมวดย่อยต้องมีในระบบ, ราคาทุน>0, ไม่ซ้ำ) → บันทึก

**แบบที่ 2 — รูปแบบ PEAK (2 ขั้น):**
- **ขั้น 1 กลุ่มสินทรัพย์:** ดาวน์โหลดเทมเพลตกลุ่ม → กรอก (หมวด/หมวดย่อย/รหัสกลุ่ม/ชื่อ/ผังบัญชี/อายุ/ซาก) → อัปโหลด → สร้าง/อัปเดตหมวด (หมวดที่ไม่มีสร้างให้อัตโนมัติ) · ต้องสิทธิ์ **แก้หมวดหมู่**
- **ขั้น 2 สินทรัพย์รายตัว:** อ้าง "เลขที่กลุ่มสินทรัพย์" + วันที่ซื้อ (YYYYMMDD) + มูลค่า + ค่าเสื่อมสะสมยกมา + วันเริ่มคิดค่าเสื่อม → สร้างทรัพย์สิน (รหัสออกอัตโนมัติ + ยกยอด legacy) · ต้องสิทธิ์ **สร้างทรัพย์สิน**

> ✅ **ลำดับสำคัญ:** นำเข้า **กลุ่มก่อน** แล้วค่อยนำเข้า **สินทรัพย์** (เพราะสินทรัพย์อ้างรหัสกลุ่ม)

## บทที่ 13 — เพิ่มทรัพย์สินด้วยมือ
ที่ทะเบียน → **"เพิ่มทรัพย์สิน"** → กรอกฟอร์ม (หมวด, มูลค่า, วันได้มา, สถานที่, ผู้ถือ, Serial) → รหัสออกอัตโนมัติ

# ส่วนที่ 4 — ใช้งานประจำวัน

## บทที่ 14 — ทะเบียนทรัพย์สิน (`/assets`) ★
หัวใจของระบบ:
- **ค้นหา/กรอง** — รหัส, ชื่อ, Serial, หมวด, สถานะ, สถานที่
- **คลิกแถว → QuickView → เปิดรายละเอียด** — เห็นข้อมูลครบ + ค่าเสื่อม + ประวัติ
- **ปุ่มเปลี่ยนสถานะ** (ขึ้นตามสถานะและสิทธิ์): ส่งอนุมัติ, อนุมัติ (หัวหน้า), ส่งซ่อม, พักใช้, จำหน่าย ฯลฯ
- **ส่งออก Excel** · **พิมพ์ฉลาก QR**

## บทที่ 15 — ฉลาก QR (`/label`)
- ทุกทรัพย์สินมี **QR Code** เข้ารหัสลิงก์ `/a/{id}` → สแกนด้วยมือถือ → เปิดหน้าทรัพย์สินแบบอ่านอย่างเดียว (เห็นรายละเอียดตามสิทธิ์)
- เลือกขนาดฉลากให้ตรงสติกเกอร์ → **พิมพ์** หรือดาวน์โหลด **PNG/SVG** เข้าโปรแกรมพิมพ์ฉลาก (เวกเตอร์ คมทุกขนาด)

## บทที่ 16 — ย้าย/โอน · ซ่อมบำรุง · จำหน่าย
- **ย้าย/โอน (Transfer):** เปลี่ยนสถานที่ของทรัพย์สิน (ต้องใส่เหตุผล) — บันทึกประวัติการเคลื่อนย้าย
- **ซ่อมบำรุง (Maintenance):** บันทึกการ ซ่อม / บำรุงเชิงป้องกัน / ตรวจสอบ / สอบเทียบ พร้อมวันที่/ค่าใช้จ่าย/ผู้ให้บริการ
- **จำหน่าย (Disposal):** ประเภท ขาย / ตัดเป็นเศษ / สูญหาย / เสียหาย / บริจาค / ตัดจำหน่าย — ใส่มูลค่าที่ขายได้ + NBV ณ วันจำหน่าย → สถานะเป็น "จำหน่ายแล้ว"

## บทที่ 17 — เอกสารแนบ (`/documents`)
คลังไฟล์แนบทั้งหมด (ใบกำกับ, รูปถ่าย, ใบรับประกัน, สัญญา) ที่ผูกกับทรัพย์สิน — แนบจากหน้าทรัพย์สินได้โดยตรง

# ส่วนที่ 5 — งานบัญชี

## บทที่ 18 — ค่าเสื่อมราคา (`/depreciation`) ★
วิธีคิด: **เส้นตรง (SL) เท่านั้น** (Phase 1) = (ราคาทุน − มูลค่าซาก) ÷ อายุ(เดือน) เท่ากันทุกเดือน
> ⚠️ ทรัพย์สินที่ตั้งวิธีคิดเป็น DB/UOP (เช่น ข้อมูลนำเข้า/ยกมา) จะ **ขึ้นเตือนสีแดง "วิธีคิดค่าเสื่อมไม่รองรับ"** และถูกกันออกจากการคำนวณ ไม่ถูกคิดเป็นเส้นตรงเงียบ ๆ — ต้องแก้หมวด/วิธีให้เป็น SL ก่อน

**ขั้นตอนปิดงวด (RunStatus 5 สถานะ):**
```
  ร่าง ──คำนวณ──► คำนวณแล้ว ──ตรวจทาน──► ทบทวนแล้ว ──ปิดงวด──► ล็อกแล้ว ──ส่งบัญชี──► ลงบัญชีแล้ว
  (DRAFT)      (CALCULATED)         (REVIEWED)        (LOCKED)          (POSTED)
```
1. **คำนวณ** — ระบบคิดค่าเสื่อมของทุกทรัพย์สินในงวดนั้น **และตรึงยอดรายชิ้น (snapshot)** ไว้กับรอบ
2. **ตรวจทาน** — เช็กตัวเลข (กดทบทวนได้ต่อเมื่อไม่มีรายการผิดพลาด)
3. **ปิดงวด (ล็อก)** — ล็อกไม่ให้แก้ย้อนหลัง + ตรึง snapshot ยอดสุดท้าย (ต้องสิทธิ์ **ปิดงวดค่าเสื่อม** = MANAGER)
4. **ส่งบัญชี** — ส่งยอดที่ตรึงไว้เข้าระบบบัญชี (ONEBOOK)

> 📌 **snapshot = ความจริงของงวด:** เมื่อรอบถูกล็อก/ลงบัญชีแล้ว หน้า "ตรวจสอบก่อนปิดงวด" รายงาน และการส่งบัญชี จะยึด **ยอดที่ตรึงไว้ตอนล็อก** เสมอ ไม่คำนวณสดใหม่ — ถ้ามีคนไปแก้ทรัพย์สินหลังล็อก ระบบจะขึ้น **แถบเตือนส่วนต่าง** (จำนวนชิ้น/ยอดที่ต่างจากที่ล็อก) ให้เห็น แต่ตัวเลขที่ลงบัญชียังตรงกับที่ล็อกไว้
> 📌 **หน้า "ตรวจสอบก่อนส่งบัญชี":** กดปุ่มส่งบัญชีแล้วจะเปิดสรุปก่อนยืนยัน — **พร้อมส่ง** (มีผังบัญชี+บริษัทครบ) กับ **ส่งไม่ได้** (ยังไม่ผูกรหัสบัญชี/บริษัท) พร้อมจำนวนชิ้น ยอดรวม และแยกตามบริษัท · ระบบส่งเฉพาะรายการที่พร้อม งวดที่ ONEBOOK ลงบัญชีไปแล้วจะไม่ลงซ้ำ (ขึ้นว่า "ลงบัญชีแล้ว")
> 📌 **บัญชีที่ลง:** ค่าเสื่อม (Dr) และค่าเสื่อมสะสม (Cr) ส่งมาจาก **ผังบัญชีของหมวดทรัพย์สิน** โดยตรง (บทที่ 8) — ตั้งผังบัญชีแต่ละหมวดให้ครบ ยอดจะลงบัญชีถูกตัวโดยไม่ต้องใช้บัญชีเริ่มต้นกลาง
> 📌 เริ่มคิดค่าเสื่อมตาม **กฎเริ่มคิด** ของนโยบาย (วันพร้อมใช้ / วันได้มา) และ **การเฉลี่ย** (เต็มเดือน/ตามวันจริง/เดือนถัดไป)

## บทที่ 19 — ตรวจนับทรัพย์สิน (`/verify`) 🎯
1. **สร้างแคมเปญ** ตรวจนับ (ต้องสิทธิ์คิดค่าเสื่อม)
2. เดินตรวจ + สแกน QR แล้ว **บันทึกผลรายชิ้น:**
   - พบถูกที่ (FOUND) · พบผิดที่ (WRONG_LOCATION) · ชำรุด (DAMAGED) · ไม่พบ (NOT_FOUND) · ไม่แน่ใจ (UNKNOWN)
3. มีการ์ดสรุป → กด **"ปิดแคมเปญ"** (ล็อกผล)

# ส่วนที่ 7 — อ้างอิงเร็ว

## ❓ FAQ

**Q: นำเข้าทรัพย์สินแล้วปุ่ม "นำเข้า" กดไม่ได้ (เทา)?**
→ บทบาทคุณไม่มีสิทธิ์ "สร้างทรัพย์สิน" (ADMIN ไม่มีตามค่าเริ่มต้น) — ใช้บัญชี ACCOUNTANT/MANAGER หรือให้แอดมินติ๊กสิทธิ์ให้

**Q: ของชิ้นเดียวกันเข้ามาซ้ำจาก 2 ระบบ จะรู้ได้ไง?**
→ หน้าคิวมีธงเตือนซ้ำด้วยเลขใบกำกับ/PO · และกันรหัส/เลขเอกสารซ้ำอัตโนมัติ (ดูบทที่ 10)

**Q: ซื้อของ 2,500 บาท ต้องขึ้นทะเบียนไหม?**
→ ต่ำกว่าเกณฑ์ 3,000 บาท = เป็นค่าใช้จ่าย ไม่ต้องขึ้นทะเบียน (เกณฑ์ตั้งค่าได้)

**Q: นำเข้ารูปแบบ PEAK ขึ้น "ไม่พบเลขที่กลุ่ม"?**
→ ยังไม่ได้นำเข้า "กลุ่มสินทรัพย์" ก่อน — ทำขั้น 1 (กลุ่ม) ให้เสร็จก่อนขั้น 2 (สินทรัพย์)

**Q: แก้ค่าเสื่อมย้อนหลังได้ไหม?**
→ งวดที่ "ปิด (ล็อก)" แล้วแก้ไม่ได้ — ต้องปรับในงวดถัดไป

## ✅ เช็กลิสต์
**ก่อนนำเข้าทรัพย์สิน:** ตั้งหมวดหมู่+ผังบัญชี+นโยบายค่าเสื่อมครบ · มูลค่า ≥3,000 · หมวดย่อยถูก
**ก่อนปิดงวดค่าเสื่อม:** คำนวณครบ · ตรวจทานตัวเลข · ไม่มีทรัพย์สินข้อมูลไม่ครบ (ดูรายงาน)

## 📑 ตารางสถานะ (สรุป)
- **ทรัพย์สิน:** รอตรวจสอบ → ร่าง → รออนุมัติ → ใช้งาน → (ส่งซ่อม/พักใช้/ย้าย) → รอจำหน่าย → จำหน่ายแล้ว/เก็บถาวร
- **รอบค่าเสื่อม:** ร่าง → คำนวณแล้ว → ทบทวนแล้ว → ล็อกแล้ว → ลงบัญชีแล้ว
- **คิวนำเข้า:** ใหม่ → กำลังตรวจ → พร้อมสร้าง → สร้างแล้ว / ปฏิเสธ / ซ้ำ / ผิดพลาด
